UIs For Ux

UIs For Ux is a collection of UI components for web development. Designed to be a tool for creating beautiful and functional user experiences.

Guide for best practices and standards by UX Design.

Starting point for your next accessible and responsive project.

Getting Started

To get started with UIs For Ux, you can download the latest release from the GitHub repository.

Features

  • Responsive design
  • Accessible components
  • Easy to customize
  • Modern design

Components

  • Animations
  • Card Slider
  • Border Animation
  • Target
  • Image Gallery
  • Modal
  • Navbar
  • Slider
